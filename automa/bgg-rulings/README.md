the base game and the official expansions. Ares Expedition and the dice game are separate games and

## Reading a ruling

Each ruling gives the question, the answer, a verbatim quote and a link to the post. Under a
heading the rulings run in date order. Tags:

- `superseded`: a later official post on the same question says something else; the link goes to it.
- `prerelease`: posted before the game came out (September 2016), when the rules were still changing.
- `prototype`: from Nick Shaw's 2022 fan prototype thread for MarsBot (2883930), before the published Automa.
- `erratum`: the printed card or rulebook is wrong and the post gives the correct version.
- `intent`: design intent that settles a question rather than a rules statement.
- `variant`: an official or endorsed variant, not the standard rules.
- `hedged`: the poster said "I think", "I would say" or similar.
- `inferred`: the post doesn't name the card or answers a question that has to be read from context.
- `house-rule-ok`: the poster said to play it however the group likes.
- `reversed`: the same poster took it back later in the same thread.

"Open conflicts" at the top of a file lists official answers that disagree with no later post
settling it, such as the 2018 and 2023 answers on Mars University's discard.

For the Automa, Nick wrote on 2026-10-13 that "forum answers from Dávid or I will supersede the
rulebook wording". What the MarsBot code actually follows, and where it chose a reading,
is in [../checklists/designer-rulings.md](../checklists/designer-rulings.md).

## Sources and caveats

Read 2026-10-29: every thread in the Rules, General, Strategy, Variants, News, Crowdfunding, Reviews
and Sessions forums of the base game and its expansions on BGG, plus the FryxGames and Stronghold
Games company forums. That is 7550 threads and 107145 posts, 2458 of them by the accounts above.

The questions and answers are paraphrased; the quote is verbatim. Some rulings read firmer than
the post, usually because an "I think" got lost, so follow the link before relying on one for code.

Superseded rulings were marked within each file. Across files only one case was marked (the
Prelude wild tag ruling, overruled in a Prelude 2 thread), so a ruling without the tag is not proof
that nothing later replaced it.
