# Big Box: official BGG rulings

3 rulings posted on BoardGameGeek by FryxGames, Stronghold Games and the Automa designers. [README.md](README.md) says who is who, how this was built, and what the tags mean. Under each heading the rulings run in date order, so a later one can overrule an earlier one.


## Rules


### Big Box replacement cards

- **Do the three Big Box replacement cards have to be used, and with which expansions?** Using them is optional; they add special tiles to the game and can be used in any combination of expansions. Cardboard tiles for them come with the Big Box or can be printed from FryxGames' PDF.  
  "You don't need to use them at all, but they will make the game a notch more fun. They can be used in any combination of expansions." ([Jacob, 2021-12-13](https://boardgamegeek.com/thread/2774714/article/39027585#39027585))
- **What extra special tiles and cards does the Big Box contain compared with the base game and expansions?** The Big Box includes 3 new special tiles and 3 alternate cards that place them, which are replacement cards for Deimos Down, Great Dam and Magnetic Field Generators. The cards are also in the Big Box promo pack but without the tiles; the tiles can be printed from the FryxGames website. The expansions otherwise add no tiles.  
  "The only exception is that the Big Box also includes 3 new special tiles and 3 alternate cards that place them. These are replacement cards for Deimos Down, Great Dam, and Magnetic Field Generators." ([Jacob, 2024-10-22](https://boardgamegeek.com/thread/3391502/article/45059319#45059319))

## Cards


### Magnetic Field Generators

- **Does the Big Box version of Magnetic Field Generators differ from the base game card?** The Magnetic Field Generators card in Terraforming Mars: Big Box instructs you to place a special tile (the 3D Magnetic Field Generators tile) and is meant to replace the base game card. The base card did not specify placing a special tile.  
  "the card that comes inside Terraforming Mars: Big Box will instruct you to place this tile. This card is meant to replace the card in the base game." ([Stronghold, 2020-06-12](https://boardgamegeek.com/thread/2446881/article/35090113#35090113))
